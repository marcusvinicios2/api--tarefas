# API DE TAREFAS

## FERRAMENTAS
- Java 21 
- Spring boot 4
- Spring web
- SQL Server
- Maven
- Spring Data Jpa

## ENDPOINTS
- GET /tasks  :  Lista tudo
- POST /tasks  :  Cria uma tarefa
- DELETE /tasks/{id} : Remove uma por vez
- DELETE /tasks : remove tudo

  ## COMO RODAR
- Crie o banco 'tasks_db' no SQL Server.
- Defina a variável de ambiente 'DB_PASSWORD' com a senha do usuário do banco.
- Rode a 'ApiApplication'.
